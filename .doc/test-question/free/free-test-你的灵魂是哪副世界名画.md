## 🧬 五维人格-审美模型

<aside>
🎨

**核心设计理念**

每位用户通过答题生成一个 **5 维人格向量**，每幅名画也有一个预设的 5 维特征向量。系统计算用户向量与所有名画向量的**余弦相似度**，匹配度最高的即为「灵魂名画」，同时展示 Top 2-4 的相似名画作为推荐。

</aside>

### 五个维度定义

| 维度 | 代号 | 低分端（1） | 高分端（5） | 测量内容 |
| --- | --- | --- | --- | --- |
| **D1: 情绪光谱** | E | 🌊 内敛沉静 | 🔥 热烈奔放 | 情绪表达的强度与方式 |
| **D2: 审美取向** | A | 📐 写实精致 | 🌀 抽象表现 | 对艺术形式的偏好 |
| **D3: 生命哲学** | L | ⚖️ 理性秩序 | 🦋 感性自由 | 对生活的态度和价值取向 |
| **D4: 能量场域** | S | 🌙 独处内省 | ☀️ 群体共鸣 | 社交能量与人际关系倾向 |
| **D5: 时间意识** | T | 🏛️ 怀旧经典 | 🚀 当下先锋 | 对时代感和创新的态度 |

每题 4 个选项，每个选项对 1-2 个维度产生 +1 或 -1 的影响。最终每个维度的得分归一化到 [1, 5] 区间，形成用户的 5 维向量。

## 📝 28 道测试题目

<aside>
📐

**题目设计原则**

- 每题 4 个选项，每选项影响 1-2 个维度（+1 或 -1）
- 28 题覆盖：D1×5 题、D2×5 题、D3×4 题、D4×4 题、D5×4 题 + 6 道跨维度综合题
- 题目风格：情景代入 + 审美选择 + 直觉反应，避免纯学术感
- 融入视觉元素（图片选择题标注★）
</aside>

## 🧮 相似度匹配算法

<aside>
🔢

**核心算法：余弦相似度（Cosine Similarity）**

不使用传统「总分 → 区间」的方式，而是将用户和名画都视为 5 维向量，计算它们之间的余弦相似度。这种方法更精准，也更能体现「每个人都是独特的审美组合」。

</aside>

### 计算流程

1. **用户答题** → 每个维度累计得分（初始值 0，选项 +1 或 -1）
2. **归一化** → 将每个维度的原始分映射到 [1, 5] 区间
    - 公式：`normalizedScore = ((rawScore - minPossible) / (maxPossible - minPossible)) * 4 + 1`
    - D1 原始分范围约 [-13, +13]，D2 约 [-13, +13]，D3 约 [-11, +11]，D4 约 [-12, +12]，D5 约 [-12, +12]
3. **计算余弦相似度**
    - `cosineSim(user, painting) = Σ(ui × pi) / (√Σui² × √Σpi²)`
    - 对 22 幅画逐一计算
4. **排序** → 相似度最高的为「灵魂名画」，Top 2-4 为「灵魂回响」
5. **百分比展示** → `matchPercent = Math.round(cosineSim * 100)`

### 评分逻辑

```jsx
// 维度索引
const DIM = { E: 0, A: 1, L: 2, S: 3, T: 4 }

// 每题选项的维度影响
const QUESTIONS = [
  // Q1
  { options: [
    { scores: { E: -1, S: -1 } },
    { scores: { E: +1, A: +1 } },
    { scores: { E: -1, S: +1 } },
    { scores: { E: +1, T: +1 } }
  ]},
  // Q2
  { options: [
    { scores: { E: -1, L: -1 } },
    { scores: { E: +1, L: +1 } },
    { scores: { E: -1, S: -1 } },
    { scores: { E: +1, A: +1 } }
  ]},
  // ... Q3 - Q22 同理，此处省略，完整数据见上方题目设计
]

// 计算用户向量
function calculateUserVector(answers) {
  // answers: [0-3, 0-3, ...] 表示每题选了哪个选项
  const rawScores = { E: 0, A: 0, L: 0, S: 0, T: 0 }
  
  answers.forEach((choice, qIdx) => {
    const option = QUESTIONS[qIdx].options[choice]
    Object.entries(option.scores).forEach(([dim, val]) => {
      rawScores[dim] += val
    })
  })

  // 各维度的原始分范围（根据题目数量计算）
  const ranges = {
    E: { min: -10, max: 10 },
    A: { min: -10, max: 10 },
    L: { min: -8, max: 8 },
    S: { min: -8, max: 8 },
    T: { min: -8, max: 8 }
  }

  // 归一化到 [1, 5]
  const vector = ['E', 'A', 'L', 'S', 'T'].map(dim => {
    const { min, max } = ranges[dim]
    const clamped = Math.max(min, Math.min(max, rawScores[dim]))
    return ((clamped - min) / (max - min)) * 4 + 1
  })

  return vector
}

// 余弦相似度
function cosineSimilarity(vecA, vecB) {
  let dot = 0, magA = 0, magB = 0
  for (let i = 0; i < vecA.length; i++) {
    dot += vecA[i] * vecB[i]
    magA += vecA[i] * vecA[i]
    magB += vecB[i] * vecB[i]
  }
  return dot / (Math.sqrt(magA) * Math.sqrt(magB))
}

// 匹配名画
function matchPaintings(userVector) {
  const results = Object.values(PAINTINGS).map(painting => ({
    ...painting,
    similarity: cosineSimilarity(userVector, painting.vector),
    matchPercent: Math.round(
      cosineSimilarity(userVector, painting.vector) * 100
    )
  }))

  // 按相似度降序排列
  results.sort((a, b) => b.similarity - a.similarity)

  return {
    primary: results[0],           // 灵魂名画
    similar: results.slice(1, 4),  // 灵魂回响 Top 2-4
    all: results                   // 全部排名
  }
}
```
